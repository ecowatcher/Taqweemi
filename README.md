# التقويم الهجري · أم القرى — تطبيق Android أصلي

تطبيق التقويم الهجري مغلّفًا بـ **Capacitor**، مع **تنبيهات أوقات الصلاة الأصلية** (تنطلق والتطبيق مغلق، بصوت أذان) — دون اعتماد على تقويم الجهاز.

البناء يتم **سحابيًا عبر GitHub Actions** — لا تحتاج تثبيت أي برنامج على جهازك.

---

## ١) النشر والبناء (مرّة واحدة)

1. أنشئ مستودعًا جديدًا على GitHub (مثلاً `Hijri_app`)، **Public** أو Private.
2. ارفع **محتويات هذا المجلّد** إلى المستودع (عبر السحب في واجهة GitHub، أو GitHub Desktop، أو git).
   الملفات المطلوبة:
   ```
   .github/workflows/build.yml
   www/index.html
   www/notify.js
   resources/adhan.wav
   capacitor.config.json
   package.json
   package-lock.json
   .gitignore
   ```
3. بمجرّد الرفع إلى الفرع `main`، يبدأ البناء تلقائيًا. (أو من تبويب **Actions** ← Build Android APK ← **Run workflow**.)
4. انتظر ~٥–٨ دقائق حتى تكتمل المهمة (علامة ✓ خضراء).
5. افتح المهمة المكتملة ← اسحب للأسفل إلى **Artifacts** ← نزّل **hijri-calendar-apk** (ملف مضغوط فيه `app-debug.apk`).

---

## ٢) التثبيت على الجوال

1. انقل ملف `app-debug.apk` إلى جوالك (أو نزّله عليه مباشرة).
2. افتحه ← قد يطلب السماح بالتثبيت من مصادر غير معروفة ← اسمح.
3. لو ظهر تحذير Avast/Play Protect «تطبيق غير معروف» = إنذار كاذب لتطبيق خارج المتجر ← ثبّت على أي حال.
4. عند أول فتح: **اسمح بإذن الإشعارات**.
5. الإعدادات ← أوقات الصلاة ← اختر مدينتك (أو GPS) ← تم.

ستُجدول تنبيهات الصلوات للأيام القادمة تلقائيًا، وتُحدَّث في كل مرّة تفتح فيها التطبيق.

---

## ٣) استبدال صوت الأذان (مهم)

الملف `resources/adhan.wav` الحالي مجرّد **نغمة مؤقتة**. لأذان حقيقي:

1. احصل على ملف أذان بصيغة **WAV** (يفضّل، متوافق مع أندرويد) — يمكن تحويل mp3 إلى wav بأي محوّل.
2. سمِّه **`adhan.wav`** بالضبط، واستبدل به الملف في `resources/adhan.wav`.
3. ارفع التغيير إلى GitHub ← يُعاد البناء تلقائيًا ← نزّل APK الجديد وثبّته.

> ملاحظة: يُفضّل WAV قصير (~٥–١٠ ثوانٍ، نغمة افتتاح الأذان) وحجم معقول. أندرويد ٨+ يربط الصوت بقناة الإشعار «أوقات الصلاة».

---

## ٤) تحديث التطبيق لاحقًا

أي تعديل (مثلاً نسخة جديدة من `www/index.html`):
1. ارفع الملف المعدّل إلى المستودع.
2. ينطلق البناء تلقائيًا ← نزّل APK الجديد ← ثبّته فوق القديم (تُحفظ بياناتك ما دام نفس `appId`).

---

## ملاحظات

- **iOS:** هذا المسار يبني APK لأندرويد فقط. تطبيق أيفون أصلي يحتاج جهاز Mac + Xcode؛ وإلا تبقى نسخة الأيفون على الـPWA.
- **أيقونة التطبيق:** حاليًا الأيقونة الافتراضية لـCapacitor. يمكن إضافة أيقونة مخصّصة لاحقًا.
- **مُعرّف التطبيق:** `com.salem.hijricalendar` (في `capacitor.config.json`).
- **الأذونات:** يضيف البناء أذونات التنبيهات الدقيقة (Exact Alarms) تلقائيًا لضمان دقّة المواقيت.
